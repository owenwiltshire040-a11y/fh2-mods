A starting point, not finished car data.

Car settings currently use a Python file. You can keep it with the project and return to it at any time.

  1. Identity & dimensionsChoose unique car and text IDs, then set weight, wheelbase and tyre sizes.
  2. Materials & lightsMatch the model’s paint, glass, trim and lamp names.
  3. Driving & cockpitCheck the engine, gears and driver positions.

Your starting car supplies the materials, engine, handling and lighting settings. These need adapting to the new model before you build. Use the checklist below to work through them.

Fields to adapt

  1. MODEL NOTES — document the model, source, licence, axes, and measurements.
  2. MEDIA — choose a unique FH2 media name (18 characters).
  3. DONOR_ZIP / GEO — filled by the app when you build.
  4. MATERIALS — map each model material to paint, glass, chrome, interior, or remove it.
  5. STEER / HIPS / EYE — place the steering wheel and driver.
  6. PHYSICS — set the car identity, engine, gears, body dimensions, tyres, brakes, suspension, and performance.
  7. LIGHTS / PRESENT — set lamp regions and Autoshow make/category display.

Keep Python syntax valid. Start from a nearby car and change the values you know; tune the rest after an in-game check.
